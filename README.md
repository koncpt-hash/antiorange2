# LP Hub TV – Extra TV

Klikalna makieta z Figmy, ta sama co artifact https://claude.ai/artifact/9TL1F32bsjm5KNWvr1H9u2. Ceny to placeholdery.

Ekrany (routing przez hash):
- Strona Telewizja (`#`) – wybór 24 miesiące / Bezterminowo, dishe, pakiety, modale Szczegóły, Lista kanałów i CMB.
- Strona Internet mobilny (`#internet-mobilny`) – przełączniki TV / Abonament 5G / Netflix, czas umowy, formularz zasięgu z planszą ładowania.
- Strona Konfigurator (`#konfigurator`) – przełącznik TV i czas umowy (24 miesiące / Bezterminowo).

Strona statyczna: `index.html` + obrazy w `assets/`. Dostęp chroniony hasłem przez `middleware.js`.
